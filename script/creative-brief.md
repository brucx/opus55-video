# Creative brief — WaytoAGI explainer video

## Ask (from the user, verbatim)
参考 WaytoAGI 飞书文章《Opus 5.5 怎样把代码变成视频：8 个精选案例与制作经验》和文中的其他内容，制作一个视频来介绍
**Opus 5.5 为什么能做成这么炫酷的视频**，以及**小白如何自己做出这么炫酷的视频**。

## Audience
WaytoAGI community: Chinese-speaking AI enthusiasts, many 小白 (no animation or programming background), who have seen
these viral Opus 5.5 videos and want to (1) understand why they look so good and (2) make one themselves.
Platforms: B站 / 视频号 / 抖音 horizontal player / X. 16:9 1920×1080, Mandarin voice-over, burned-in Chinese subtitles.

## Promise of the video (what viewers must leave with)
1. 原理：Opus 5.5 不直接"画"视频——它输出文本，即代码、分镜和制作指令；浏览器/图形引擎按时间把每一帧画出来，FFmpeg
   编成视频。画面 = render(t)。30 秒 × 30 帧 = 900 帧，不等于调用模型 900 次。
2. 为什么炫：好看来自叙事 + 有限而一致的视觉规则 + 统一时间轴 + 声音落点 + 迭代检查，而不是"模型会画画"。
   8 个案例各示范一招（贯穿对象、风格规则、分层制作、数据约束、产品事实、固定资产、动作驱动、多模型分工）。
3. 小白怎么做：准备一个能跑代码的 AI 工作环境（如 Claude Code）→ 选一条路线（HyperFrames / Remotion / 纯 HTML 渲染，
   或装 Lemo-Opuscar 这类风格插件）→ 用模板写清需求 → 先要分镜和风格帧、一个短镜头小样 → 按"时间点+问题+期望"反馈 →
   检查成片并保留工程。从 15–30 秒的第一支短片开始。

## The meta hook (use it)
This video is itself made exactly that way: Claude Opus 5.5 (in Claude Code) wrote the scene code, the timeline and the
Python music; headless Chrome captured every frame; FFmpeg encoded it; the voice is TTS (edge-tts, Microsoft neural voice).
One of the case videos literally shows a command palette entry "Every frame is code" (lists-006). Working title:
**《每一帧，都是代码》** — subtitle like「Opus 5.5 炫酷视频的秘密 + 小白上手指南」. Weave the meta angle in honestly:
say what WE did only if true (see "Our pipeline" below).

## Length and pacing
- Target 3:15–3:45 total. Narration ≈ 850–1000 Chinese characters (Yunxi voice at +6 % speaks ≈ 5 chars/s incl. pauses),
  plus music-only moments (cold open beats, title, case montage breaths, end card).
- 14–22 scenes. One idea per scene, one focal point per screen. First 3 seconds must hook (DIRECTOR.md rule).
- Chapters (shown as a tag top-left): e.g. 00 开场 / 01 原理 / 02 为什么炫 / 03 小白上手 / 04 幕后.

## Writing for the voice (TTS) and subtitles
- Short spoken sentences (≤ 25 chars between commas ideally). Conversational, confident, not salesy. No emoji.
- Avoid symbols the TTS reads badly: no "→", "/", "=", "×", parentheses, quotes around code, "@handles", URLs, English
  abbreviations that should be spelled (write "每秒 30 帧" not "30fps"; say "F F mpeg" only if needed — better "编码工具 FFmpeg").
  Product names are fine as words: Opus 5.5, Claude Code, Remotion, HyperFrames, FFmpeg, Blender, After Effects.
- A line's `text` is both the subtitle and the TTS text; give `say` only when pronunciation must differ.
- Numbers as digits in text (TTS reads them fine): 900、1,704 → write "1704" in say if commas cause issues.
- Don't read on-screen code or the prompt template aloud verbatim — the screen shows it, the voice summarizes.

## Visual vocabulary available (code-rendered, see script/design.md)
Kinetic Chinese typography; code blocks with typing; terminal/chat windows; film strips and frame counters; timeline
scrubbers with keyframes; node/flow diagrams with animated packets; cards and checklists; number counters; thumbnail wall
of ~60 real case posters (assets/wall/); real case footage excerpts (credited) from assets/cases/*.mp4 at chosen ranges;
WaytoAGI logo; particles/grids/glows; split screens (frame vs code); morphing shapes; iris/wipe/push/zoom transitions.
Not available: stock footage, AI-generated imagery, real people on camera, screen recordings of apps we did not render.
(We can re-create UI like a terminal or a chat box in HTML.)

## Facts and honesty rules
- Use research/brief.md and research/source-article.md as the source of truth. Opus 5.5: text+image in, text out
  (Anthropic docs). No official Anthropic "video feature" — never imply one.
- Author self-reports stay labelled (e.g. 「作者自述：约 90 分钟构建、4 小时渲染、40 美元」); never present as verified.
- Each case excerpt on screen carries the author handle; voice may say the work's name or description instead of the handle.
- Claude Code requires a paid plan (Pro/Max/Team/Enterprise/Console); the free plan doesn't include it; Anthropic serves
  only supported regions — put this as a brief on-screen note, not a long spoken detour.
- Remotion: free for individuals / small teams; larger for-profit companies need a license (on-screen footnote if Remotion
  is recommended). HyperFrames: Apache 2.0. Lemo-Opuscar: MIT.
- Don't promise "one prompt → finished film". The article's message is iteration: storyboard → style frames → short
  sample → feedback with timestamps → full piece → checks.

## Our pipeline (true statements you may use in the meta/outro)
- Script → narration.json → edge-tts voice with word timings → timeline.js (every scene and caption timed to the voice).
- Scenes are HTML/SVG/Canvas functions of time; Chrome (headless) seeks each frame and captures it; 6 renderers in parallel.
- Music: generated by a Python program (chords, bass, drums, arpeggio synthesized with numpy), sections follow the
  scene "energy"; sound effects are synthesized too; mix ducks music under the voice; loudness −16 LUFS.
- Case footage excerpts are real frames from the authors' posts, used for commentary with credit.
- Final numbers (frames, lines of code, render minutes) will be filled in after the render — write placeholders like
  {{FRAMES}} {{CODE_LINES}} {{RENDER_MIN}} {{SCENES}} in on-screen text only, never in the voice.
