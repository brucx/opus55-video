# 制作报告：时间与 Token

统计口径：Claude Code 本机会话记录（主会话 1 份 + 子代理 91 份），模型 Claude Opus 5.5，effort max。

## 时间

从提出需求到交付 v3，墙钟约 **13 小时**（2026-10-01 11:52 → 10-02 00:56，北京时间）。

| 阶段 | 时段 | 用时 |
|-|-|-|
| 调研：8 个案例下载与逐帧分析、工具与 Lemo-Opuscar 资料 | 11:52–12:47 | 55 分钟 |
| 脚本：3 版初稿 → 3 位评审 → 合成 → 事实与语音核实 | 12:47–14:55 | 2 小时 08 分 |
| 14 个场景并行开发（作者 → 独立评审 → 修复） | 14:58–18:20 | 3 小时 22 分 |
| 第一次整片渲染与混音，v1 预览 | 18:20–18:55 | 35 分钟 |
| 第一轮整片审查 + 8 个案例重做，v2 | 18:55–21:35 | 2 小时 40 分 |
| 上传 Tigris、加封面、修 Logo、改标题（v2.1） | 21:43–22:45 | 约 1 小时 |
| 第二轮审查 + 旁白重写，v3 | 22:48–00:56 | 2 小时 08 分 |

- 主会话实际工作时间约 **4 小时 23 分**，其余时间主要在等待后台子代理和渲染。
- 子代理累计工作 **38.8 小时**（91 个，最多 6 个并行）。
- 1080p 整片渲染 5 次，每次 6–7 分钟（6 个无头 Chrome 并行），合计约 32 分钟。
